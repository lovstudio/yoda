# 一个 URL 为什么会变成文件：Yoda 终端跨行链接修复记

一张终端表格把同一个 URL 拆成两行甚至三行。URL 开头可以正确打开，右键末尾的 `secret.html` 却出现文件菜单。

问题经历了三个阶段：从拼接最后一段，到按表格单元格恢复任意段数的完整 URL，最后定位到 Web 链接与文件路径之间的语义优先级冲突。

最终方案建立统一的终端链接目标解析器：完整网址优先，文件路径兜底；悬停、Cmd+点击和右键共享同一优先级。文章讨论为什么用户看到的一个链接，在产品内部也必须只产生一个语义实体，以及为什么当前实现选择从 xterm buffer 恢复逻辑 URL，而没有额外维护 transcript 到屏幕坐标的映射。
