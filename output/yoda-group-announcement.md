Yoda v0.14.0 已发布。

Yoda 是给 Claude Code / Codex 等编程 Agent 配的桌面驾驶舱：多会话并行编排、任务与分支管理、用量统计、技能/提示词/自动化/团队资源库，一个 app 全收。

这版主要改账号体验：

- 支持本地昵称覆盖，账号名称会在设置、首页、登录流程等入口统一显示更新后的昵称。
- 设置页账号面板更清爽：隐藏不必要的 username 摘要，把退出登录收进账号操作区。
- 近期几版也补了生成任务标题、摘要、改写时的语言处理开关，默认更克制；项目概览、侧边栏快捷操作、多配置对比、MaaS/ZenMux 用量与模型发现也都陆续更新了。

适合已经在同时跑多个 Agent、多个 worktree、多个模型配置的同学升级。
