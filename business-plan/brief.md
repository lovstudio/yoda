# Yoda — BP Brief

Updated: 2026-07-26  
Version: v1.0  
Language: zh-CN

## Financing task

- Audience: 中国早期科技投资人、AI 创业赛事评委与潜在设计伙伴
- Stage: Seed / 商业验证早期
- Target presentation: 15 页 / 8–10 分钟
- Financing ask: 200 万元人民币，或 30 万美元
- Instrument / equity: 出让 10% 股权；最终条款以正式协议为准
- Validation window: 18–24 个月
- Decision requested: 投资并成为首批设计伙伴，把已完成的产品闭环推进为可重复增长

## Product definition

- Literal category: 面向超级开发者的本地优先 AI Harness 工作台
- Comparator: Agent 时代的 IDE——统一意图、执行、证据与交付
- Category creation: 集成委托环境（Integrated Delegation Environment），即让人敢把真实工作交给 AI、又始终保留控制与责任的工作系统
- Chosen one-line: **Yoda 让创造者敢把工作，真正交给 AI。**
- Core user: 用 AI 独立交付过去需要多人协作成果的超级开发者
- Initial payer: 需要跨设备连续性、自动化与长期任务的个人；需要共享资产、权限、审计和预算控制的教育机构与小型团队
- Core job: 从想法到发布，持续组织 Agent、上下文、工程证据与最终决定
- Early wedge: 高频使用 Coding Agent 的独立开发者与 AI 原生创造者
- Adjacent users: 内容创作者、高校与训练营、AI 原生小团队
- Long-term market: 每个创造者都拥有并能驾驭自己的 AI 工作系统

## Investment thesis

- Problem: 模型和 Agent 的执行能力快速上升，但人的注意力没有增加；多会话、上下文、分支、测试、成本和责任让“可靠委托”成为新瓶颈
- Product insight: Agent 能跑只是执行问题；人是否敢委托，取决于过程是否可见、证据是否可查、结果是否可回退
- Solution: Yoda 把 Runtime、Session Control、Harness Assets、Delivery System 和 Human Control 组织为一条从意图到发布的闭环
- Why now: 模型能力趋于基础设施化，Agent 可独立执行时长上升，价值正在从“谁能生成”迁移到“谁能可靠地驾驭与交付”
- Evidence already proven: 31 种 Agent Client、本地/SSH/移动端与 Relay 路径、Task/Feature/Worktree/Review/Release 交付闭环；截至 2026-07-26，54 Stars、18 Forks、76 个 GitHub Release、近 14 天 141 个独立 Cloner
- Evidence not yet proven: 全量 DAU、D7/D30 留存、个人付费转化、机构年约和可重复获客效率
- Business model: 本地核心开源；个人为连续性与自动化付费；机构为协作秩序、治理与私有部署付费
- Defensibility: 供应商中立的运行时适配、跨会话上下文、工程证据闭环、可复用 Harness 资产，以及真实高频工作流形成的迭代速度
- Founder fit: 创始人同时是第一重度用户、产品经理、开发者和首批渠道；用 Yoda 持续开发 Yoda

## Presentation strategy

Core message: **代码正在廉价化，可靠委托正在升值。Yoda 要成为创造者驾驭 AI 的控制面。**

Supporting proof:

1. 产品不是概念：真实 Task、Feature、Harness、Worktree、Review 与多端控制已经形成闭环。
2. 平台不是单一 Agent 壳：31 种 Agent Client 与供应商中立架构保护用户的选择权。
3. 执行力已被证明：公开仓库上线约两个半月，完成 76 个 GitHub Release。
4. 融资目的明确：不是放大未经证明的收入，而是验证留存、个人付费、机构年约与增长效率。

## Known boundaries

- 任何 Clone、Release 下载、设备授权都不等于活跃或留存用户。
- TAM/SAM/SOM 中的适配率、价格和三年账户数均为假设或经营目标。
- 竞争象限是基于公开定位与当前功能的定性判断，不代表第三方厂商自我定义。
- 本轮金额和股权为提案口径，经营主体、股权结构与最终交易条款需在尽调中对齐。
